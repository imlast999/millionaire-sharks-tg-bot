=======================================================
🦈 MILLIONAIRE SHARKS — CARPETA DE VIDEOS / GIFS DE COMPRA
=======================================================

Coloca aquí los videos, GIFs o imágenes de los 10 tiburones del proyecto.

Formatos soportados:
- Videos animados: .mp4, .webm, .mov
- GIFs: .gif
- Imágenes: .jpg, .jpeg, .png, .webp

Comportamiento:
- Cada vez que alguien realice una compra (o uses `pnpm run simulate:buy`),
  el bot elegirá uno de los archivos de esta carpeta de forma ALEATORIA.
- El video o GIF se enviará con el mensaje de compra como título (caption).
- Si esta carpeta está vacía, el bot enviará el mensaje de texto habitual automáticamente.
